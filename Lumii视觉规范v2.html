从格子界面
换成一块极光画布

这一版的核心不是换个主色，而是换了界面的组织方式：整个应用共用一层带极光渐变的画布， 各栏不再各自铺不透明底色、不再用 1px 线切开，而是靠毛玻璃透出深浅。 本文给出全部设计令牌、材质配方与逐个元素的 CSS，取值与当前分支源码一字不差，可直接复制。

改了什么

七条改动，按影响面从大到小。后面每一节都是对其中一条的展开。

项旧新
画布 各栏各自 #fff / #f5f6f7 实底 全局一层 --app-canvas：#F7F7FA + 三团极光
分栏 border-right: 1px solid 毛玻璃 + box-shadow 发丝线，会话栏完全透明
主色 蓝紫 #5B67E8 浅紫三档 #B695F5 / #A47BF0 / #8C5FE4
描边 border: 1px solid var(--line) box-shadow: 0 0 0 1px rgba(20,21,26,.06)
头像 按名字散列的饱和色圆形 圆角方；人与会话中性灰，只有智能体保留品牌渐变
字体 系统默认 Instrument Sans（拉丁）+ JetBrains Mono（元信息）
栏结构 导航栏内含会话列表，导航栏可拖宽 会话栏独立成栏（只在「对话」出现）；导航栏定宽 216 / 60
一条贯穿全篇的规则：不要用 border 画线。 半透明的栏与卡片压在渐变上，1px 实线会在浅色背景里显出一条硬边， 而 box-shadow: 0 0 0 1px 是半透明的墨，会跟着背景一起走。 除表格内部的 divide-y 外，全站已无 1px 边框。
02

色彩

一支紫贯穿全局，一支薄荷只出现在渐变里。灰阶是暖中性（#1F2329 系）， 不要换成纯黑纯灰。

主色 · 三档

#B695F5--primary-light渐变高光端。只在渐变里出现，不单独用。
#A47BF0--primaryACC。填充、图标、选中态、徽标、描边。
#8C5FE4--primary-h / --primary-inkhover、渐变暗端，以及所有紫色小字。
#F6F2FE--primary-bg徽标底、@自己的芯片底。
#FAF8FE--primary-bg-weak文件夹树里祖先行的弱高亮。
紫色的字用 --primary-ink，不用 --primary。 #A47BF0 压在白底是 3.15:1、压在自己那条淡紫气泡上只有 2.75:1； #8C5FE4 分别是 4.31:1 和 3.76:1。填充与图标用前者，小字一律后者。

中性 · 灰阶

#F7F7FA--bg画布底色，极光叠在它上面。
#FFFFFF--panel被「抬起来」的东西：选中行、弹层、卡片。
#DEE0E3--line结构边界（现多由发丝阴影代替）。
#EBECEE--line-soft块内部分隔线，比外框浅一档。
#1F2329--ink正文。白底 16:1。
#646A73--ink-2次要文字、未选中的导航项。
#8F959E--ink-3占位符、时间、图标默认色。
#5C5F6B头像字色压在 rgba(20,21,26,.05) 上约 6.2:1。

语义色

#34C724--ok / --ok-bg #EAFBE7成功、在线。
#FF8800--warn / --warn-bg #FFF5E6告警。
#F54A45--danger / --danger-bg #FEF1F1危险、失败、@到我的提示。
#7F3BF5--purple / --purple-bg #F3EDFF标签类紫，与主色区分开。

品牌渐变球 · 四色

logo、favicon、智能体头像、极光画布全部只从这四支取色，颜色再多也还在一个家族里。

#C4B5FD薰衣草球体主色、渐变起点。
#A47BF0紫与主色同一支。
#F9B4C8粉只在球体与智能体渐变里。
#93E8D8薄荷画布左下那团、下划线与标题渐变的收尾。

09

无障碍与降级

对比度：已知的取舍

#A47BF0 压在纯白上是 3.15:1，达不到 WCAG AA 对正文的 4.5:1。 这是照设计稿的用色 —— 主色只出现在短标签、图标、已经有底色衬托的小字上， 正文一律 --ink（16:1）。哪天要做合规，要动的是这几处用法，不是把主色调回深紫。

组合对比度结论
#1F2329 on #fff16.0:1正文，充裕
#5C5F6B on rgba(20,21,26,.05)6.2:1头像缩写，充裕
#8C5FE4 on #fff4.31:1紫色小字的下限
#8C5FE4 on 淡紫气泡3.76:1@芯片，过线
#A47BF0 on #fff3.15:1仅限图标与徽标
#A47BF0 on 淡紫气泡2.75:1禁止，用 --primary-ink

有两条测试钉着这些门槛：chat-mention-card.test.tsx（@芯片 ≥3:1）与 theme-color-guard.test.ts（旧色不得回流源码）。

动效

全部动效都要在 prefers-reduced-motion: reduce 下关掉：登录页极光漂移、 lumii-blink 加载动画（改成静态 opacity: .55）、抽屉滑入。 时长基准：微交互 .16s，抽屉 .18~.2s，下划线 .32s，环境级 24s。

毛玻璃的降级

backdrop-filter 不支持时（老 Firefox、部分安卓 WebView）， 半透明白仍会显示，只是不模糊 —— 界面仍可读，不需要额外兜底。 但要注意性能：大面积 backdrop-filter 在低端机上会掉帧， 已限制在导航栏、输入框、气泡、登录卡四处，不要再扩散。

焦点

可交互元素一律保留可见焦点环：outline: 2px solid rgba(164,123,240,.28) + outline-offset: 1px。不要为了视觉整洁写 outline: none。

10

落地清单

给接手改造的同学：以下是这套规范里最容易写错的几条。

  • ✕不要用 border: 1px solid 画容器边框。换成 box-shadow: 0 0 0 1px rgba(20,21,26,.06)。表格内部的 divide-y 是唯一例外，且颜色必须写在 divide-[...] 工具类上 —— 写在父元素 inline style 里会静默失效。
  • ✕不要给栏铺不透明底色。除导航栏（玻璃 .55）外，会话栏与主区都是透明的，画布直出。铺一层白会把「呼吸感」整个抹掉。
  • ✕不要用 --primary 当小号文字色。紫色的字一律 --primary-ink。
  • ✕不要给头像上色。只有智能体的兜底头像用品牌渐变，人与会话一律中性灰。
  • ✕不要在气泡里用实色底。--bubble-mine 是半透明的，实色会在渐变上糊出方斑。
  • ✓圆角按尺寸走阶梯。小控件 5~9px、行与卡片 11~12px、气泡 14px、输入框与大卡 18~20px。
  • ✓lucide 图标线宽降到 1.7~1.8。默认的 2 在这套通透的界面里太重。
  • ✓元信息用 --font-mono。时间戳、编号、快捷键、表头、眉标、头像缩写 —— 但正文与标题不要用。
  • ✓新写的颜色必须来自本文的色板。theme-color-guard.test.ts 会拦下旧橘 #E8734A 与 vendor 旧蓝 rgba(0,82,204)；新增取值请一并加进那份守卫。
